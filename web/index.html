How to configure, rotate and revoke a key
  1. Create the key in the provider's own console (the Official setup button on each card goes there).
  2. Put it in .env on this machine — for example GOOGLE_MAPS_SERVER_API_KEY=AIza.... Never in localStorage, never in a query string, never in a commit.
  3. Restart the server; GET /api/v1/config/health reports whether the shape looks right (it never echoes the value).
  4. Press Test connection. Billable probes ask for confirmation first and tell you what one request costs.
  5. To rotate: create the new key, replace the line in .env, restart, test, then delete the old key in the console.
  6. To revoke: delete the key in the console. The card will move to Authentication failed on the next test, and the app falls back to the local index / built-in map instead of failing.
